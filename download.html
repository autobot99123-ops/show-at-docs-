Installation

  1. Download the APK using the button above.
  2. Open the downloaded APK from your notifications or file manager.
  3. If Android asks, allow installation from the relevant source (browser or file manager).
  4. Install ShowAt.
  5. Open ShowAt and create your account or log in.

Blocked install? Android blocks unknown-source apps by default. The allow prompt appears during installation — approve it once for your browser or file manager. See Troubleshooting for details.
