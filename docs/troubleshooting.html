Troubleshooting

Fixes for the most common ShowAt problems.

Provider shows "Not connected" after pasting a link

  1. Type the profile URL in the Links section first (for example https://github.com/your-name).
  2. Press Save so the URL is stored.
  3. Press Link in Connected Accounts for that provider.
  4. Open your Techy page to trigger a sync.

Streak node shows "linked" but no count

  • Stats refresh roughly every 12 hours — linking syncs immediately, otherwise open your Techy page and wait for the refresh.
  • Only public activity counts. Private work never appears.
  • A streak needs consecutive active days ending today or yesterday — one quiet day resets it to an honest zero.

My post, project, or tool doesn't appear

  • Tools and resources: only approved (published) items are listed — pending ones wait for review. See Tools.
  • Projects: check the project saved successfully and you are viewing the right profile.
  • Anything else: pull to refresh; check you are logged in as the account that created it.
