Building

Projects

Projects are the work you showcase: what you built, what stage it is at, and how far along it is.

Creating a project

A project holds a title, description, category, technologies, tools, cover image, GitHub repository URL, and live demo URL. Unfinished form work is kept on your device as an offline draft; the project is created only when you publish.

  • Repository import — paste a GitHub repo URL (plus an optional live URL) to pre-fill the title, description, and detected stack from the public repository.
  • Cover and demo — upload a cover image and link a live demo so visitors can try the work.

Project lifecycle

Every project carries a status that describes its stage:

  • Idea · Planning · Building · Testing — work in progress.
  • Shipped · Completed — finished and delivered.
  • Maintaining — live work you keep improving.

Presentation

Published projects appear on your profile, in the community project listings, and as nodes on your Techy canvas. Repository-backed projects also get a repository visualizer showing the repo structure from a cached snapshot.
