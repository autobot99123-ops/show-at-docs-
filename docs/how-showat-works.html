Getting Started

How ShowAt Works

Four pieces — profile, Techy, projects, community — fed by your real activity.

The flow

  1. You create a profile with your identity, skills, and links. See Profile.
  2. You connect platforms like GitHub and LeetCode. Public activity syncs in. See Connected Accounts.
  3. You add projects with milestones. Progress is derived from what you record. See Projects.
  4. Techy visualizes it all — skills, platforms, projects, streaks — on one canvas. See Techy.
  5. The community discovers it — students find your work, attach, and message you. See Community.

Where data comes from

  • You type it: identity, skills, links, posts, projects, milestones.
  • Platforms provide it: GitHub and LeetCode public activity syncs periodically (roughly every 12 hours) after you link them.
  • ShowAt derives it: project progress comes from milestones; streaks come from consecutive active days.

Honesty rule: ShowAt shows empty states instead of invented data. A provider with no synced activity shows as linked, not as fake numbers.
