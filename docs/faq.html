FAQ

Common questions about ShowAt, answered briefly.

Do I need an account to read these docs?

No. This documentation site has no login — read anything. You only need an account inside the ShowAt app itself.

Does ShowAt replace GitHub or LeetCode?

No. GitHub stays the source of code and LeetCode the source of problem-solving activity. ShowAt presents them together with your projects and community. See What is ShowAt?

Why is my streak zero when I was active?

A streak counts consecutive active days ending today (or yesterday while today is still young). One quiet day resets it. Also note only public activity syncs — private repository work never appears. See Connected Accounts.

How often does platform activity sync?

Roughly every 12 hours, triggered when you open your Techy page. Linking a provider syncs immediately.

Why isn't my tool submission listed?

Submissions wait in pending until reviewed. Only published tools and approved resources are listed. Rejected ones carry a moderation note. See Tools.

I lost form text — where did it go?

The app keeps unsent form work as an offline draft on your device and restores it when you return. The database is written only when you press Save. If a form looks empty, check you are logged in as the same user.
