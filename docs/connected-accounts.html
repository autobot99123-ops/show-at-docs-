Your Identity

Connected Accounts

Link your technical platforms so your public activity appears on your Techy canvas.

Linking a platform

  1. Paste your profile URL in the Links section (for example https://github.com/your-name) and save.
  2. Press Link in Connected Accounts for that provider.
  3. Open your Techy page. Synced stats appear as streak nodes on the canvas.

What syncs from each provider

  • GitHub — public activity syncs from your link: live streak, public event counts, last active day, and a trailing ~90-day activity grid (the limit of GitHub's public, no-login API).
  • LeetCode — public streak, submission totals, and a full-year activity grid from your public submission calendar.
  • Kaggle — display-only link. Kaggle offers no public streak API, so no activity syncs.
  • HackerRank — display-only link, for the same reason.
  • LinkedIn — treated as a profile link.

Private activity never syncs. Only public data is read — for example, your GitHub graph on ShowAt will not match github.com if most of your work is in private repositories. Stats refresh roughly every 12 hours.
