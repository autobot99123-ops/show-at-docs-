Community

Tools

A student-curated library of tools — discover them, submit your own.

Discovering tools

Browse tools by category with details on what each tool does, how it works, pricing notes, tags, and community ratings. Only published tools are listed.

Submitting a tool

Anyone can submit a tool with its name, URL, category, description, how-it-works, pricing, and tags. Submissions go through community review before appearing publicly:

  • Draft — your unfinished submission, visible only to you.
  • Pending — submitted and waiting for review.
  • Published — approved and listed for everyone.
  • Rejected — not approved, with a moderation note explaining why.

Approval applies to tools and resources only. Posts, projects, profiles, and messages publish directly — no review queue.
