Community

Messages

Direct messaging with collaborators — built in, no external app required.

Conversations

Start a chat from a student's profile or continue one from the messages area. Conversations update in real time, and unread counts clear when a conversation is read.

Message privacy

You control who can start a chat with you:

  • Everyone — any student can message you first.
  • Attaches only — strangers must attach with you before starting a chat. Ongoing chats always keep working.
