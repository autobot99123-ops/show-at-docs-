Getting Started

Introduction

This is the official documentation for ShowAt. It explains what ShowAt is, how it works, and how to use each part of it.

What this site is

This website is documentation only. It describes the ShowAt product, documents its existing features, and answers common questions.

There are no accounts, feeds, messages, or settings here.

How to use these docs

  • New to ShowAt? Start with What is ShowAt? and How ShowAt Works.
  • Setting up your presence? Read Profile, Techy, and Connected Accounts.
  • Showcasing work? Read Projects, Progress, and Milestones.
  • Meeting people? Read Community, Tools, Resources, and Messages.
  • Stuck? See FAQ and Troubleshooting.

A note on accuracy

These docs describe the ShowAt implementation as it exists today. They do not include planned features, statistics, testimonials, or partnerships. If something here disagrees with the app, the app is the source of truth — and the docs should be updated.
